# Uế Mạch v1

Seven original-alpha PNG atlases, each 1536×1024. Ordinary creatures occupy the top row (idle, windup, release); elites occupy the bottom row in the same order. Boss cells: idle, dig, emerge, jump, attack, roll.

Runtime loads one texture per family and extracts six frames from source alpha. No background masking, baked projectiles or VFX. Phaser frames retain the original image pixels. Art generated with the built-in imagegen tool; final prompt set and generation source paths are saved under `art/monsters/ue-mach-v1/prompts.md`.

Used by Stage Kháng Chiến; the original Sandbox art remains available for its existing system fixtures.
