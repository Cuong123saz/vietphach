# Kiêu Ngạo — four forest maps

Original 1536×1024 PNG artwork created with the built-in imagegen tool. Runtime terrain is 1800×1200. No baked characters or monsters. Map 1 forest-edge-v1.png; Map 2 silent-bridge-v1.png; Map 3 stone-boundary-v1.png; Map 4 sealed-heart-v1.png.

The return journey reuses maps 3, 2, 1. NPC removal, corruption flow, navigation and sound are controlled by the stage, not painted into these files.

Prompts and sources: `art/kieu-ngao/prompts.md`. Story and implementation notes: `docs/design/Kieu-Ngao-Mui-Ten-Cuoi-Rung.md`.
